# 油站网点地图管理

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Element Plus、Leaflet
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据默认保存在浏览器localStorage中，方便后续扩展接口、权限、图表或地图能力。

## 班次库存流水与版本校验

- 值班员通过「登记库存」按打开页面时的版本提交库存；若期间有人先保存，本次不写入并提示按最新库存重新核对。
- 每座站保留班次库存流水（早班/中班/晚班按提交时间自动划分），流水列表可按油站、按班次筛选查看。
- 库存低于容量两成自动转为「库存紧张」，补到警戒线以上自动恢复「营业中」；暂停营业站只记流水，是否恢复由站长手动「流转状态」处理。
- 删除油站时，该站的流水记录一并清除。
